 # 🧠 Quiz Game Application

An interactive Quiz Game Application developed as part of Internship Task 03 (Alternative).  
The application displays multiple-choice questions, collects user responses, calculates the score, and shows the final result.

---

## 📌 Features

- Multiple-choice questions
- Interactive answer selection
- Real-time score calculation
- Final score display
- Clean and responsive UI
- Built using pure JavaScript

---

## 🛠️ Technologies Used

- HTML5 – Structure of the application
- CSS3 – Styling and layout
- JavaScript (ES6) – Quiz logic and interactivity

## 🧩 How It Works

1. Questions are stored in a JavaScript array of objects
2. Each question contains:
   - Question text
   - Options
   - Correct answer index
3. User selects an option
4. The app checks the answer and updates the score
5. After all questions, the final score is displayed
